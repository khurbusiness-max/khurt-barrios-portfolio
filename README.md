# KB Portfolio

Premium black-and-gold Next.js portfolio website for Khurt Barrios.

## Stack

- Next.js App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide icons

## Run

```bash
npm install
npm run dev
```

Then open `http://localhost:3000`.

## Customization

- Replace the hero portrait at `public/images/khurt-portrait.png`.
- Replace the working/editing background at `public/images/editing-setup.png`.
- Edit portfolio cards in `app/page.tsx` inside the `portfolioCategories` array.
- Edit services, brands, editing styles, and testimonials in the arrays near the top of `app/page.tsx`.

The source includes comments next to the hero image layers and portfolio placeholders showing where to replace videos/images.
